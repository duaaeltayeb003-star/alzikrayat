⬛ Alzikrayat

⬛ Project Overview
A web platform designed for university students to capture and share campus moments, featuring photo management and comment interactions.



⬛ Tech Stack
▪️ HTML5
▪️ CSS3
▪️ JavaScript
▪️ Bootstrap 5
▪️ Native PHP (Custom MVC Pattern)
▪️ MySQL Database
▪️ Apache Server (XAMPP)



⬛ How to Run
▪️ Start **Apache** and **MySQL** in XAMPP.
▪️ Place the `alzikrayat` folder inside the `htdocs` directory.
▪️ Create a database named `alzikrayat_db` via **phpMyAdmin** and import the tables.
▪️ Open your browser and navigate to:
  `http://localhost/alzikrayat/public/`
